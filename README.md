# ECST CCNA Challenge Labs

منصة تدريب على شهادة **CCNA 200-301**: الطالب بيحل غرف من أسئلة عملية، التصحيح فوري، وكل غرفة بتفتح اللي بعدها. فيها لوحة شرف ولوحة أدمن لإدارة الغرف والطلبة.

مكتوبة بـ **HTML و CSS و JavaScript عادي** بدون أي مكتبات أو build tools.

## التشغيل

1. نزّل المشروع (`git clone` أو Download ZIP).
2. افتح `index.html` في المتصفح (Firefox أو Chrome). مفيش تنصيب ولا سيرفر.

> **مهم:** البيانات متخزنة في المتصفح (`localStorage`) على الجهاز ده بس. تغيير المتصفح أو البروفايل أو مسح الكاش معناه بيانات جديدة. استخدموا نفس المتصفح ونفس طريقة الفتح دايماً.

## الحسابات

- **الطلبة:** بيسجلوا من صفحة التسجيل.
- **الأدمن الافتراضي:** `admin@ecst.edu` (الباسورد في `js/store.js`). **غيّروه قبل أي استخدام حقيقي.**

## هيكل المشروع

```
index.html            الصفحة الرئيسية وترتيب تحميل الملفات
style.css             الشكل العام والمتغيرات
css/                  أنماط خاصة (الأسئلة، الـ Terminal، الأدمن)
js/store.js           الحالة والتخزين والنقاط + نظام أنواع الأسئلة (QuestionTypes)
js/app.js             الراوتر والهيدر والإشعارات
js/rooms.js           صفحة المسار وصفحة الغرفة
js/auth.js            تسجيل الدخول والحساب
js/admin.js           الأدمن ولوحة الشرف
js/questions.js       أنواع الأسئلة الإضافية
js/terminal.js        محاكي Terminal
js/exam.js            وضع الامتحان
data/                 الغرف والأسئلة
docs/CONTRACT.md      العقد بين الأجزاء (شكل البيانات وواجهات الكود)
tests.html            اختبارات تلقائية (لازم كله PASS)
```

## للمطورين

- اقرأوا `docs/CONTRACT.md` قبل أي تعديل.
- افتحوا `tests.html` في المتصفح قبل وبعد أي تعديل، ولازم يبقى كله **PASS**. الاختبارات بتشتغل على مفتاح تخزين منفصل (`ecst_test`) وما بتلمسش بيانات المشروع.
- كل واحد بيشتغل على **branch** خاص بيه وبيعدّل ملفات جزئه بس، وبعدين Pull Request.
- مفيش ES modules: الملفات بتتحمّل بـ `<script src>` عادي علشان المشروع يشتغل من `file://`.
